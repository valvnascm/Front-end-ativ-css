# Front-end-ativ-css

Projeto acadêmico de um site educativo sobre teoria musical.

O site apresenta conceitos básicos de música, como:

Notas musicais

Intervalos

Escalas musicais

Formação de acordes

Escala pentatônica

Tecnologias utilizadas: HTML, CSS.

O site é feito para pessoas que querem entender um pouco melhor sobre teoria musical e não tem um conhecimento vasto sobre o assunto, ou seja, uma boa porta de entrada
